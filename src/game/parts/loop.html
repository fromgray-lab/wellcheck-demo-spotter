🔎 진단 · 개선 카드
단계별 첫 시도 성공률·오클릭 밀집·찬스 의존·시간 초과·판정 이의·스테이지 피드백을 합쳐 문제 지수를 매기고, 규칙으로 처방을 제안합니다. 적용하면 콘텐츠 오버라이드로 저장돼 모든 플레이어에게 즉시 반영되고, 이후 기록과 전후 비교로 자동 검증됩니다.

적용 전/후 같은 단계의 첫 시도 성공률과 평균 오클릭을 비교합니다. 후속 5회 이상 쌓이면 자동 판정(✅ 개선 확인 / ⚠️ 악화 → 되돌리기).

문제 지수 = 0.35×(1−첫시도성공률) + 0.25×min(1, 평균오클릭/2) + 0.15×찬스사용률 + 0.10×시간초과율 + 0.15×min(1, 이의/3) + 0.2×(오클릭 밀집 시). 시도 3회 미만 단계는 "데이터 부족"으로 보류. 오버라이드는 힌트·찬스·팁·정답영역(추가)·과제문구를 바꿀 수 있고, 되돌리면 원본으로 복귀합니다.
