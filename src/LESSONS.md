# 틀린시연찾기 — 학습된 규칙 (LESSONS)

사용자 의견·오답 데이터에서 뽑아낸 **재발 방지 규칙**입니다. 일간 자동 개선 루프와 콘텐츠를 만드는 모든 세션은
작업 전에 이 파일을 읽고, 신고된 스텝 하나만 고치지 말고 **같은 패턴을 가진 다른 스텝까지** 찾아 고칩니다.
새 규칙은 맨 아래에 추가합니다(형식: 규칙 · 근거 · 적용 방법). 근거가 사라진 규칙은 지우지 말고 `폐기:`로 표시합니다.

## 화면·레이아웃
- **L1. 문제(지시문)는 화면 상단에 크게.** 근거: "문제가 아래에 있어서 잘 안 보인다"(2026-11-10, 팀장 전달) → v60. 적용: 플레이 화면에서 지시문을 가리거나 아래로 내리는 UI를 넣지 않는다. 토스트·배너는 지시문 띠를 덮지 않는다.
- **L2. 보드는 실제 화면 · 고해상도 · 화면만 봐도 이해되는 쪽.** 근거: "화면이 너무 깨짐도 심하고 문제인 장면이 많다"(2026-11-10) → v61. 적용: 같은 흐름을 보여 주는 더 선명한 원본(체험존 시뮬레이터 등)이 있으면 교체를 제안. 가로 1200px 미만 보드는 리포트에 매번 표시.
- **L3. 글은 짧게.** 근거: 범례·하단 문구가 "너무 많다"는 지적(v57~v59). 적용: 안내문은 한 줄, 세부는 접기 안으로.

## 문제·힌트 문구
- **L4. 누를 대상의 종류(메뉴/버튼/탭/칸)를 문구에 명시.** 근거: M2 `m2a`에서 3명이 왼쪽 메뉴 대신 화면 가운데 '초대문자 보내기' 버튼을 누름(2026-10-25) → v54. 적용: 보드에 다음 단계 화면이 이미 떠 있으면 특히.
- **L5. "~한 뒤 ○○" 식 문구는 이전 동작을 다시 누르게 만든다 — 지금 화면 상태를 먼저 말한다.** 근거: M2 `m2i` '담당의사 선택 후 저장'에서 2명이 돋보기부터 누름 → v55("골라진 상태 —"). 적용: task가 이미 끝난 동작을 언급하면 '~된 상태 —'로 시작. 점검: 2026-11-12, 4건 수정(task에 '뒤/후/다음'이 든 27스텝을 보드와 대조 — 앞 동작이 화면에 이미 끝나 있는 m5d·m5g·la9·ca4만 '~된 상태 —'로. m1b·m1c·m2c·m5a처럼 보드의 칸이 비어 있는 스텝은 '~된 상태'라 쓰면 화면과 어긋나므로 그대로 둠. '확인 후'는 누르는 동작이 아니라 위반 아님. 판정 기준: 앞 동작의 결과가 보드에 보일 때만 위반).
- **L6. 같은 라벨의 버튼이 보드에 2개 이상이면 위치를 문구·찬스에 적는다.** 근거: v16 독립 검수(임시저장 5개·작성완료 2개 등). 적용: 정답 후보가 여럿이면 둘 다 정답 영역으로 넣거나 위치를 특정. 점검: 2026-11-13, 1건 수정(243스텝의 목표 라벨을 보드 OCR(tesseract kor)로 찾아 정답 영역 밖에 같은 글자가 있는 31스텝을 보드와 대조 — 대부분 표 머리글·안내문·화면 제목 속 같은 낱말이라 버튼 중복 아님. 실제 같은 버튼이 여럿이고 문제에 위치가 없던 m5c('혈당 입력' 버튼 3개)만 문제에 '「혈압/혈당 입력 안내」 메시지 아래'를 넣음. 판정 기준: 같은 라벨이 '누를 수 있는 것'으로 2개 이상 보이고, 문제·힌트 어디에도 위치가 없을 때 위반. OCR은 작은 글씨를 놓치므로 0건이어도 '중복 없음'을 보장하지 않음).
- **L7. 힌트는 문제의 목표어를 반복하지 않는다.** 근거: v16 검수. 적용: 힌트는 위치·색·주변 요소로. 점검: 2026-11-11, 0건 수정(전 243스텝 중 힌트가 문제와 낱말을 공유하는 32스텝 확인 — 모두 "교육상담 열"·"박고당 행"처럼 열·행 이름을 위치 기준으로 쓰고 위치·색을 덧붙여 위반 아님. 판정 기준: 힌트에서 문제와 겹치는 낱말을 빼면 위치·색·주변 요소가 하나도 남지 않을 때만 위반).

## 사실·콘텐츠
- **L8. 수치·제도·절차는 소스 매뉴얼(또는 화면에 적힌 문구) 근거 없이 쓰지 않는다.** 근거: 검수에서 '1시간→1분', 근거 없는 '배터리 50%' 등 발견. 적용: 근거 없는 내용은 비워 두고 제안으로 올린다.

## 의견 수집
- **L9. 의견은 한 번 탭으로 남길 수 있어야 쌓인다.** 근거: 자유 기재 + 보내기 구조에서 훈련 42건 동안 의견 0건(~2026-11-10) → v62. 적용: 입력 단계를 늘리는 변경 금지. 수집률(의견/훈련)이 10% 아래면 리포트에서 원인 분석.
- **L10. 저장은 '도착 확인'까지 해야 저장이다.** 근거: 시트 권한 문제로 화면엔 '저장됨'인데 실제로는 유실(2026-10-21~23). 적용: 전송 경로를 바꾸면 실제 시트 도착을 확인하고, 기기 보관분 재전송 장치를 유지.
